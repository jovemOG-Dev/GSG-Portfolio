# Fotos das conexões

Coloque aqui a foto de cada pessoa, com o nome em minúsculas, sem acento e separado por hífen:

    fernando-tsuda.jpg
    filippo-valiante-filho.jpg

O `index.html` já aponta para esses nomes. Se o arquivo não existir, o card mostra as iniciais.
Use fotos quadradas (por volta de 240x240 px) e peça autorização da pessoa antes de publicar.
